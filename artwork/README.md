# The Visual Art of Scam-A-Lot

![Scam-A-Lot poster](Scamalot.png)

The [PDF file](Scam-a-lot.pdf) contains four pages. The first page is the entire poster scaled for printing on an 11 x 17 inch ("tabloid" size) paper. Pages 2 through 4 are formatted for 8.5 x 14 inch (legal size) paper; these are "tiled" images which slightly overlap so you can trim off the margins and glue them to a half sheet of poster board (14 x 22 inches) to make a larger poster.
